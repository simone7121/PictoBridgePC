# Changelog

All notable changes to PictoBridgePC are documented here.

## Unreleased

- Added the PySide6 chat interface with Light/Dark mode persistence.
- Added automatic serial-port selection, port switching and clearer connection
  errors.
- Added online DSi users, optimistic outgoing messages and a 256×80 drawing
  canvas.
- Added the official active drawing polygon extracted from the supplied BIN/WAB
  capture.
- Added lossless received BIN/JSON captures and bounded PNG previews.

## 0.1.0

- Initial experimental ESP32-to-DSi PictoChat bridge.
