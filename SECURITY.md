# Security policy

## Scope

PictoBridgePC is experimental hardware/protocol software. Security reports are
welcome for the PC client, serial protocol handling and repository contents.

## Reporting

Please do not publish real DSi captures, personal conversations, serial logs or
hardware credentials in a public issue. Contact `dev@simonedanna.it` with a
reproducible description and sanitized evidence.

The project does not provide a security guarantee for the radio stack or the
prebuilt experimental firmware image.
