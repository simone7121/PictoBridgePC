# Support

Before requesting help:

1. install the dependencies from `requirements.txt`;
2. run `python -m unittest -v test_pc`;
3. verify that only one program owns the ESP32 serial port;
4. reproduce the issue with the terminal client when possible;
5. remove personal data from logs and captures.

Include the operating system, Python version, ESP32 family, selected COM port,
firmware image or source revision, and the exact sanitized error message.

Do not include files from `ricevuti/` unless they contain no private content.
